轻透截图的首个公开预览版：截图、透明 PNG 抠图和 GIF 录制。

The first public preview of QingTou: screenshots, transparent PNG cutouts, and GIF recording. The app interface is currently in Simplified Chinese; usage guides are available in Chinese and English.

## 下载与使用 / Download

- Windows x64 用户下载 **QingTou-v0.9.1-windows-x64.zip**，解压到可写目录，运行 **QingTou.exe**，无需安装。
- Download **QingTou-v0.9.1-windows-x64.zip**, extract to a writable folder, and run **QingTou.exe**.
- `Source code` 为源码归档，不能直接运行。`SHA256SUMS.txt` 用于校验下载文件。
- `Source code` archives contain source, not a runnable application. Use `SHA256SUMS.txt` to verify downloads.

## 主要功能 / Features

- 区域截图和矩形、箭头、画笔、文字、马赛克标注。
- 魔棒抠图：圆形拖动选取相似颜色，支持累积、减选、大小与容差调整、连续区域和柔边。
- 保留或移除选区，输出透明 PNG；抠图后可调整截图框或「收紧到选区」，减少空白。
- 区域 GIF 录制，目标 10 帧/秒，最长 60 秒，输出宽度最多 1280 像素。
- 自定义全局快捷键、系统托盘、截图时隐藏主面板、Esc 退出当前截图。
- Region capture and annotations; color-based cutouts with an adjustable circular brush, additive/subtractive selection, tolerance, and feathering.
- Transparent PNG output, resizable capture bounds, and trimming to selected content.
- Region GIF recording, customizable hotkeys, tray controls, hide-on-capture, and Esc cancellation.

## 使用说明与反馈 / Help and feedback

默认截图快捷键为 **Ctrl + Alt + Q**，GIF 为 **Ctrl + Alt + G**。更新前请从托盘退出旧版。

Default hotkeys: **Ctrl + Alt + Q** for screenshots and **Ctrl + Alt + G** for GIF recording. Exit the old instance from the tray before updating.

这是预览版本；渐变、阴影、杂色与前景背景近似色仍可能需要多次选取和手动调整。HDR、混合 DPI 多屏、远程桌面等场景仍需进一步验证。

This is a preview. Gradients, shadows, noisy images, and similar foreground/background colors may need multiple selections and manual adjustments. HDR, mixed-DPI displays, and remote desktop need further validation.
