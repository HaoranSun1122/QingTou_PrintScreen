## 本次改进 / What's improved

- **拖动选色提速**：减少对整张截图的重复扫描，复用一笔拖动中的边界计算。
- **局部预览更新**：只刷新选区变化及相邻轮廓，降低拖动时的重复计算。
- **点选直接累积**：新增选点无需每次重放全部历史操作。
- 保留连续区域 / 全图相似、累积、Alt 减选、整笔撤销、容差调整、透明 PNG 和抠图后缩框等现有功能。
- **Faster color-selection strokes** with fewer full-image scans and reusable edge checks within a stroke.
- **Partial preview updates** covering changed selections and neighboring outlines.
- **Incremental click selection** without replaying the full history for each new point.
- Contiguous/global matching, additive selection, Alt subtraction, whole-stroke undo, tolerance controls, transparent PNG output, and resizing after cutouts remain available.

## 验证结果 / Validation

- 本机 1920×1080 离屏模拟拖选（包含选区与预览计算）从约 **2.26 秒降至 63 毫秒**，该场景约提速 **35 倍**。这是单一本地场景，实际表现随图片与电脑配置变化。
- **1,764 组**随机点选、拖选与加减选序列，新旧选区及预览像素一致。
- 默认图像与界面回归测试通过，覆盖连续选区、累积 / 减选、撤销、透明 PNG、裁框和局部预览。
- A local offscreen **1920×1080** stroke fixture, including selection and preview computation, improved from about **2.26 s to 63 ms**, roughly **35×** for this fixture. Actual results vary with image content and hardware.
- **1,764** randomized click/drag/add/subtract sequences matched the previous selection and preview pixels exactly.
- Default image and UI regression tests passed, including selection modes, undo, transparent PNG output, reframing, and partial previews.

## 如何更新 / Updating

从托盘退出旧版，再用新版 `QingTou.exe` 替换原文件。保留原有 `QingTou.ini` 可继续使用已有设置；软件没有自动更新功能。

Exit the old instance from the tray, then replace `QingTou.exe`. Keep `QingTou.ini` to retain settings. Updates are manual.

这是预览版本。抠图基于颜色与连通性，复杂照片、前景与背景近似色等仍可能需要手动加减选；HDR、混合 DPI 多屏和远程桌面仍需进一步验证。

This is a preview. Color-based selection may need manual additions or subtraction for complex photos and similar foreground/background colors. HDR, mixed-DPI displays, and remote desktop need further validation.
